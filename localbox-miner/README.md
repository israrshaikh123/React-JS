# 📦 LocalBox Miner

A React-based offline data management application.

## 📝 Project Description

LocalBox Miner allows users to add, edit, and delete records while persisting data locally using localStorage. No backend or API is used.

## 🚀 Features

- Add new records
- Edit existing records
- Delete records
- Clear all records
- Data persists on page refresh (localStorage)

## 🧩 Component Structure

- **App.jsx** — Central state management
- **RecordForm.jsx** — Add/Edit form
- **RecordList.jsx** — Records table
- **RecordRow.jsx** — Single record row

## ⚛️ React Concepts Used

- useState
- useEffect
- Props
- Events & Handlers
- Conditional Rendering
- List Rendering
- localStorage Integration
